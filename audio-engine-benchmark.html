Reverb engine comparison

This compares Bitbounce’s production reverb implementation with Elementary’s WebAssembly convolver using the same deterministic stereo input, seeded impulse response, and dry/wet mix. It measures offline render throughput and output similarity on this browser and device.

Run it in the same browser and device you use for Bitbounce. Keep other heavy work closed while it runs. The first pass warms up each engine; the reported median is based on the later passes.
